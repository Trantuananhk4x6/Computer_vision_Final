# Object Tracking Application

A full-stack application for object tracking in videos and live camera streams using YOLOv8 and DeepSORT.

## Features

- Upload and process videos for object detection and tracking
- Live camera tracking for real-time object detection
- Track and count people and animals
- History of all tracking sessions with statistics
- Analytics dashboard with charts and trends
- Responsive and animated UI

## Architecture

- **Backend**: Flask (Python)
- **Frontend**: React with Tailwind CSS
- **Object Detection**: YOLOv8
- **Object Tracking**: DeepSORT
- **Database**: SQLite

## Prerequisites

- Python 3.8+
- Node.js 14+
- CUDA-capable GPU (recommended for performance)
